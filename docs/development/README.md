# Development notes

Working documents for people changing Metalcyte, kept for the record. They describe
how measurements were made, what was tried, what did not work, and what is planned. A
user of the library needs none of this: the documentation for users is one level up,
and the numbers that matter are summarised in `docs/PERFORMANCE.md`.

- `API_CONTRACT.md`: the dtypes, tolerances and device guarantees every new function must keep.
- `BENCHMARK_HISTORY.md`: per-operation timings and the optimisation history, pass by pass.
- `MEASUREMENTS_2026-10.md`: the full account of the October 2026 measurements (100 000 cells,
  the real atlases, a million cells, energy, ablation, scaling, agreement), including what
  did not work.
- `PLAN_APPLE_SILICON.md`: status and the next engineering items.
- `MANUSCRIPT_MATERIALS.md`: which result backs which claim in the paper.
